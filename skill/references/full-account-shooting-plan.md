# 柠檬舍友官号拍摄规划 & 竞品视频素材运用

## 官号定位
品牌老板/主播原生沟通人设。像真人在镜头前跟老粉聊天，不端不装、有情绪起伏、拒绝播音腔。多数真人出镜口播（老板/主播本人），宿舍实景/产品区实景，鼓励随手拍质感，不追求棚拍精致。

## 四大内容类型（各15个选题的思路，首期每类做5条起步）
1. **产品口播**（核心带货）— 把卖点讲进人心，边讲边演示（按压/铺床/拎包），数据口头带过。选题：老宿舍没空调一晚降温 / 为什么敢4年防塌+15天试睡 / 一整套值在哪 / 黄色床垫老宿舍高级感 / 卷包4斤8小个子怎么扛
2. **宿舍装饰**（场景种草）— 泛化到宿舍生活，画面大于口播，前后对比明显，黄色床品当视觉主角。选题：老宿舍改造vlog / 学生党百元改造 / 没空调自救指南 / 室友来蹭睡参观 / 开学第一顿布置。
3. **产品问答**（专业答疑）— 从评论区/私信真实问题取材，用「有个朋友问我」开场立专业信任。选题：90×190/200怎么量 / 记忆棉闷不闷塌不塌 / 与弹簧乳胶区别 / 能洗吗过敏能用吗 / 厚度怎么选7公分够吗。
4. **售前售后问答**（信任建立）— 老板态度诚恳、把风险说在前头。选题：15天试睡能否退谁出运费 / 4年防塌怎么赔怎么算塌 / 开学改地址发货快不快 / 踩雷找谁 / 立减200是真优惠吗。

## 共性结尾（所有类型统一）
一句话总结钩子 + 「今晚直播间」引导 + 口播「还有啥想问先进直播间」+ 固定CTA字幕卡：**柠檬舍友床垫·领睡个好觉券·限时立减200**。

## 拍摄执行
- 场地：老宿舍样实景（铁架床/硬板/暖灯，能看到真实硬板床对比）+ 产品实操区（铺床/按压/卷包/拎袋）
- 器材：手机竖屏、固定机位+手持补拍特写、补光灯（凸显黄色床品）、领夹麦
- 出镜：老板本人为主，可配一名舍友/员工搭话（问答/装饰适合）
- 时长：口播/问答 30-60s，宿舍装饰 vlog 45-90s

## 竞品/达人视频运用（用户会发对标链接）
用户可能发抖音达人测评链接要求参考甚至「根据那些增加专业QA」。注意：
- **必须先逐个打开链接看章节结构和口播打法，不能只看标题猜**（用户原话纠正「你得进链接看啊看人家怎么写的」）。抖音网页版可用 browser_navigate 打开，页面底部「章节要点」AI 摘要 + 章节时间轴能拿到结构骨架；评论区是真实学生痛点金矿。
- **但竞品/达人视频里的专业数字 ≠ 本品牌数据**。例：某测评号说「外罩克重188」「背面防滑硅胶粒」「枕头记忆棉层2s回弹/支撑棉1秒回弹」，这些是第三方口播，**不是用户给过的柠檬舍友官方参数**。要用来写官方QA必须先用中文确认「这是不是你们产品的真实参数」。没确认就写 = 编造。曾就此向用户确认时她打断要求继续补（说明可补但须以真实为准）。
- **真实竞品信息（从评论区和跨平台比照获得）**：学生主动求对比的竞品是 **兰希、本屋创品**；学生价格敏感（评论「太贵了给50元代金券」）；扩品类需求是床帘、六件套。可做对标 QA。

## Excel 选题库交付（用户要的表格式交付物）
列结构：类型 | 序号 | 选题 | 50字回复大纲 | 300字成稿（成稿按口播节奏一般170-220字即可念出来40-60秒，若用户坚持300字再扩写）。生成用 openpyxl，表头黄色底+冻结窗格+按类型分色+自动换行+列宽调好。默认每类型给5条即可（用户嫌60条太多）。
