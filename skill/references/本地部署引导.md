# 引导：本地部署解析 API（装完 Skill 后自动执行）

当用户安装本 Skill 并表达以下意图时，**主动进入本引导流程**，一条龙带着做完，不要中途停下等确认：
- "装好了" / "怎么用" / "怎么开始"
- "我要拉抖音视频" / "解析视频" / "抓对标视频"
- "部署 API" / "本地部署"

## 你要做的事（按顺序，一口气做完）

### 第 0 步：先探测环境
检查本机是否已装 Python，以及程序目录在哪：

```bash
python --version || python3 --version
ls ./
```

判断程序目录：本包内 `program/` 就是解析 API 源码。若用户已有自己的部署，直接用他的。

### 第 1 步：一句话说清这套东西是什么
告诉用户：
> 你要的"拉对标视频"能力，靠一个本地跑的小服务实现（抖音/TikTok 解析 API）。
> 它跑在你自己电脑上，用你自己的账号 Cookie，数据不经任何第三方。

### 第 2 步：一键部署
判断系统，让用户运行对应脚本（Windows 双击 `一键部署.bat`，Mac/Linux 跑 `./一键部署.command`）。
脚本会自动：建虚拟环境 → 装依赖 → 检查 Cookie → 启动服务。

如果脚本报错，按下面排查：
- `python 不是内部命令` → 没装 Python 或没勾 PATH，引导去 python.org 装 3.10+，勾选 Add to PATH
- 依赖装不上（网络慢）→ 脚本已用阿里云镜像；仍失败就换 `-i https://pypi.tuna.tsinghua.edu.cn/simple/`
- 端口 8000 被占用 → 改 `program/config.yaml` 里 `Host_Port: 8000` 为别的端口（如 8001）

### 第 3 步：带他填 Cookie（关键，最容易卡住）
抖音有风控，**不填 Cookie 什么都解析不了**。手把手给步骤：
1. Chrome 打开 https://www.douyin.com 并登录
2. F12 → Network 标签 → 刷新页面
3. 点任意一个请求 → Request Headers 里找 `Cookie:`
4. 整行值复制（很长，一串 `xxx=yyy; zzz=www;`）
5. 粘贴进 `program/crawlers/douyin/web/config.yaml` 的 `Cookie: ""` 引号中间
6. 重启服务生效

> ⚠️ 提醒用户：Cookie = 账号登录凭证，只放本地，别发给任何人、别传 git。

### 第 4 步：验证跑通
服务起来后：
```bash
curl "http://127.0.0.1:8000/api/douyin/web/fetch_one_video?aweme_id=视频ID"
```
或直接让用户浏览器打开 http://127.0.0.1:8000 粘贴抖音链接解析。
跑通 = 拿到 JSON（含视频直链、标题、作者等）。

### 第 5 步：接回脚本创作（本 Skill 的主线）
一旦 API 可用，**立刻回到 zhaom-script 的创作流程**：
- 用户给对标视频链接 → 用本地 API 拉取该视频的标题/文案/章节信息
- 按 `references/douyin-benchmark-playbook.md` 拆解结构
- 再写脚本

**这才是"部署 API"的真正目的**：给写脚本提供真实对标素材，不是为部署而部署。

## 端口与地址速查
- 本地首页：http://127.0.0.1:8000
- API 文档（Swagger）：http://127.0.0.1:8000/docs
- 抖音解析接口：`/api/douyin/web/fetch_one_video?aweme_id=<id>`
- 端口配置文件：`program/config.yaml` → `API.Host_Port`
- Cookie 配置文件：`program/crawlers/douyin/web/config.yaml`

## 红线
- 不要把用户 Cookie 写进任何会分享的文件
- 不要把解析服务暴露到公网（本地 127.0.0.1 即可）
- 抓取内容仅用于对标学习/创作参考，不得原样搬运他人视频
